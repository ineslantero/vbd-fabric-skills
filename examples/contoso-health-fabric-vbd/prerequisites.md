# Contoso Health — Workshop prerequisites

**Please complete by Friday 15 January 2027.** Items marked ⚠️ are blockers.

## 1. Fabric tenant & capacity ⚠️

- **Capacity SKU:** **F64** minimum, running in **West Europe**. F32 will run but the RTI lab will queue.
- **Tenant settings** (Fabric admin portal → Tenant settings):
  - `Users can create Fabric items` — enabled for the workshop security group.
  - `Git integration` — enabled tenant-wide.
  - `Copilot in Fabric` — enabled (currently in preview; attendees will see a banner).
- Reference: [Enable Microsoft Fabric for your organization](https://learn.microsoft.com/fabric/admin/fabric-switch)

## 2. Licences ⚠️

- Power BI Pro (or PPU) × 12 attendees. Direct Lake demos will not work without Pro.

## 3. Attendee setup

- Laptop with a modern browser (Edge or Chrome), 8 GB RAM minimum.
- Teams access for the hybrid delivery.
- VS Code + Fabric extension — optional but recommended for the Data Science lab.

## 4. Data

Contoso will **not** provide claims data. A synthetic healthcare-claims dataset is generated by `/vbd-data` and shipped in `data/` — the workshop stays out of PHI scope end-to-end.

## 5. Access checklist (per attendee)

- [ ] Signed in to `app.fabric.microsoft.com`.
- [ ] Can see the `contoso-vbd-jan2027` workspace.
- [ ] Can create a Lakehouse (verifies capacity + tenant setting).
- [ ] Power BI Pro / PPU licence assigned.
- [ ] For the RTI lab: `Real-Time Hub` visible in the workspace switcher.

## Troubleshooting

- **Can't create Fabric items** → check the `Users can create Fabric items` tenant setting and confirm the workspace is assigned to the F64 capacity.
- **No capacity visible** → confirm the F-SKU is running (not paused) and the workspace has been assigned to it.
- **SSO issues** → attendees must sign in to Contoso's home tenant, not a guest tenant.
- **RTI features missing** → confirm West Europe region rollout; some RTI features are region-gated.
