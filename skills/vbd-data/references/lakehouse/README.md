# Wide World Importers sample dataset

The Lakehouse Lab reference tutorial uses the **Wide World Importers (WWI)** Parquet sample dataset. The public download URL that shipped with the SP tutorial retired in 2025 and no maintained replacement exists.

## What to do

- Use the `data/*.csv` files generated by `/vbd-data` — they're shaped to match WWI (one fact + 4-5 dims with clean foreign keys).
- If the customer specifically wants the WWI Parquet sample, ask the CSA to source it from the current [Fabric Lakehouse tutorial](https://learn.microsoft.com/fabric/data-engineering/tutorial-build-lakehouse) or the [fabric-samples GitHub repo](https://github.com/microsoft/fabric-samples), which are the maintained locations for sample data now.
- Load whatever you end up with into the Lakehouse via **Get data → Upload files** or a Copy pipeline pointed at the CSA-hosted location.

## What's in this folder

- `dimension_customer.csv` (65 KB) — shape reference for a WWI dim table. Column list mirrored by `/vbd-data` when generating the customer's dimension files.
